# Limitations and reproducibility boundaries

This project is deliberately published with explicit boundaries.

## Missing historical artifacts

The original historical Cónclave experiment driver and several raw result artifacts are not available. The recovered forward engine and parameter package do not recreate the entire optimization process.

## Conflicting historical summary

Preserved research records disagree on the exact historical holdout drawdown. Because the source artifacts required to reconcile that discrepancy are missing, performance figures are not used as headline portfolio claims in this repository.

## Cost realism

Historical validation did not fully model every implementation cost. Slippage, funding, taxation, and crash execution require separate treatment before any real-capital interpretation.

## Statistical search correction

A formal Deflated Sharpe Ratio over the complete search process remains an open item. This matters because the project conducted a large hyperparameter search and therefore must account for selection effects.

## Forward evidence

Forward paper validation is ongoing. Short paper samples are operational checks, not statistical proof of predictive performance.
